# 🐾 AnimalQuiz

**AnimalQuiz** este o aplicație desktop dezvoltată în **C# (Visual Studio 2022)**, creată pentru a-i ajuta pe copii să învețe animalele într-un mod distractiv și interactiv.

---

### 🕹️ Cum se joacă?
* **Ascultă:** Aplicația redă sunetul unui animal.
* **Alege:** Copilul trebuie să dea click pe imaginea corectă a animalului respectiv.
* **Feedback:**
    * ✅ **Răspuns corect:** Primești o recompensă vizuală!
    * ❌ **Răspuns greșit:** Apare o "bilă roșie".
* **Final:** Primești o surpriză (imagine/sunet) în funcție de cât de bine te-ai descurcat.

### ⚙️ Secțiunea de Administrare
Aplicația permite configurarea completă:
- Adăugarea, editarea sau ștergerea întrebărilor.
- Gestionarea sunetelor și a imaginilor printr-un fișier text sau bază de date.
- Setarea pragului de scor pentru recompensele finale.

---

### 🛠️ Detalii Tehnice
* **Limbaj:** C#
* **Mediul de dezvoltare:** Visual Studio 2022
* **Tehnologii:** .NET Desktop Development, Lucru cu fișiere, Multimedia.
